# Developer Guide 70: Managing File Overwrites Safely with Force Flag

## Objectives
Step-by-step guidance on managing file overwrites safely with force flag within the Universal Music Import Engine ecosystem.

## Steps
1. Note that attempting to overwrite an existing export file throws an error by default.
2. Supply the `--force` (`-F`) flag to explicitly authorize overwriting.
3. Confirm that the previous target file is safely replaced upon successful completion.
