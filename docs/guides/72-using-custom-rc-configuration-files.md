# Developer Guide 72: Using Custom RC Configuration Files

## Objectives
Step-by-step guidance on using custom rc configuration files within the Universal Music Import Engine ecosystem.

## Steps
1. Create a `.musicimportrc` JSON file in your project or home directory.
2. Define default settings (e.g., format, batch size, BOM flag).
3. Run `music-import import <playlist>` without options to verify defaults are applied.
