# Developer Guide 74: Handling Windows Excel CSV BOM Encoding

## Objectives
Step-by-step guidance on handling windows excel csv bom encoding within the Universal Music Import Engine ecosystem.

## Steps
1. Add the `--bom` flag when exporting to CSV format.
2. Open the exported CSV file in Excel on Windows.
3. Verify that non-Latin characters (Japanese, Arabic, Cyrillic) display without encoding artifacts.
