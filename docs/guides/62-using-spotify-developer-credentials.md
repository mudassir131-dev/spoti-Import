# Developer Guide 62: Using Spotify Developer Credentials

## Objectives
Step-by-step guidance on using Spotify developer credentials within the Universal Music Import Engine ecosystem.

## Steps
1. Export `SPOTIFY_CLIENT_ID` and `SPOTIFY_CLIENT_SECRET` in your shell.
2. Alternatively pass `--client-id` and `--client-secret` flags.
3. Ingestion executes via authenticated OAuth provider.
