# Developer Guide 71: Batch Importing Multiple Spotify Playlists

## Objectives
Step-by-step guidance on batch importing multiple spotify playlists within the Universal Music Import Engine ecosystem.

## Steps
1. Pass multiple playlist identifiers or URLs separated by spaces to `music-import import`.
2. Specify an output directory using `--out-dir ./exports`.
3. Review the terminal execution summary indicating total playlists and tracks ingested.
